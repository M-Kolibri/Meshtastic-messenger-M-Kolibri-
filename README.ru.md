**Language:** [English](README.md) | [Русский](README.ru.md)

Децентрализованный Android-мессенджер с глубокой словарной компрессией («Колибри-код») и сквозным шифрованием (E2EE) для работы поверх радиосетей LoRa / Meshtastic без интернета и серверов.

## 🎯 О проекте
Стандартный размер пакета в сетях LoRa (Meshtastic) жестко ограничен (~200–240 байт), что делает передачу длинных текстов в UTF-8 неэффективной. **m-kolibri** решает эту проблему на уровне Android-приложения:
* **Работает с платами «из коробки»:** подключается по Bluetooth (BLE) к стандартным модулям (LilyGO T-Beam, Heltec V3 и др.) через официальный API Meshtastic (`PortNum.PRIVATE_APP`) без необходимости перепрошивки.
* **Полная автономность (P2P):** отсутствие серверов, регистрации и привязки к номерам телефонов.
* **Модульные словари:** языковые базы (`ru.bin`, `en.bin`) загружаются отдельно, снижая вес самого APK.

## ⚙️ Архитектура и технологии

### 1. Алгоритм сжатия «Колибри-код»
Вместо посимвольной передачи текст преобразуется в 3-байтовые индексы статических словарей (до 50–61 слова в одном LoRa-пакете):
* **Русский модуль (Двухуровневый бинарный код, 24 бита):** 2 байта на основу слова (65 536 лемм) + 1 байт на флексии и окончания (256 грамматических модификаторов).
* **Английский модуль (Base32 / Base36):** 3-значный код емкостью 32 768 (Base32) или 46 656 (Base36) словоформ.
* **Обработка исключений:** неизвестные слова передаются посимвольно через управляющий префикс.

### 2. Криптография и безопасность (E2EE)
* **Обмен ключами:** ECDH на эллиптической кривой **Curve25519** (32-байтные публичные ключи передаются при личной встрече через QR-код).
* **Шифрование трафика:** поточный шифр **ChaCha20** или **AES-256-CTR** (0 байт прироста к размеру пакета) + 8-байтный счетчик `Nonce` для защиты от Replay-атак.
* **Локальное хранилище:** зашифрованная БД **SQLCipher** на устройстве.

### 3. Структура полезной нагрузки (Payload)

| Поле | Размер | Назначение |
| :--- | :---: | :--- |
| `Sender ID` | 4 байта | Локальный адрес отправителя |
| `Receiver ID` | 4 байта | Адрес получателя (`0xFFFFFFFF` для общего канала) |
| `Nonce` | 8 байт | Счетчик пакетов (защита от повтора) |
| `Flags / Lang` | 1 байт | Тип данных и код языкового словаря |
| `Encrypted Data`| до 183 байт | Поток сжатых кодов слов (3 байта/слово) |
